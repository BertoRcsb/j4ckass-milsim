# Visao Geral

## Projeto

J4CKASS MILSIM

## Slogan

> MUITA PROSA, POUCA MIRA

## Descricao

Criar uma aplicacao web leve, gratuita para execucao local ou hospedagem de baixo custo, desenvolvida em ASP.NET Core MVC (.NET 8), seguindo principios de Clean Architecture, Clean Code, seguranca por padrao e facil manutencao.

O portal sera o site oficial da comunidade J4CKASS MILSIM, um grupo brasileiro de amigos que jogam juntos.

O portal deve transmitir:

- camaradagem;
- organizacao;
- profissionalismo;
- espirito MILSIM.

## Objetivo final

Este projeto nao deve ser apenas um site.

Ele deve ser a base de aprendizado continuo para evolucao em:

- C#;
- ASP.NET Core;
- Banco de Dados;
- Seguranca;
- Arquitetura Limpa;
- DevOps;
- Docker;
- CI/CD.

Todo codigo deve ser escrito pensando em legibilidade, manutencao, seguranca e crescimento futuro.
